# 单例模式（Singleton）

## 一、意图

保证一个类在程序运行期间只有一个实例，并提供一个全局访问点来获取该实例。单例模式通过隐藏构造方法、由类自身控制实例化过程，向调用方暴露统一的获取入口，从而避免多实例带来的状态不一致与资源浪费问题。

## 二、使用场景

- 需要全局唯一对象的场景，如配置管理器、日志记录器、线程池、连接池。
- 需要共享资源的访问控制点，如打印机后台服务、注册表。
- 类实例创建代价较大且可被复用，如重量级缓存、运行时上下文。
- 想要为整个系统提供一个统一的"门面"或"上下文"对象。

## 三、结构

```
        ┌──────────────────────────┐
        │        Singleton         │
        ├──────────────────────────┤
        │ - instance: Singleton     │  ← 静态私有字段，持有唯一实例
        ├──────────────────────────┤
        │ - Singleton()            │  ← 私有构造，禁止外部 new
        │ + getInstance(): Singleton│  ← 静态方法，唯一获取入口
        │ + describe(): String     │  ← 业务方法
        └──────────────────────────┘
                  ▲
                  │
   ┌──────────────┼──────────────────────┐
   │              │                      │
 饿汉式        懒汉式（双重检查锁）   静态内部类
```

## 四、角色说明

- **Singleton（单例类）**：持有自身唯一实例的引用，构造方法私有化，对外提供静态 `getInstance()` 方法。
- **Holder（内部持有者）**：在静态内部类实现中承担"延迟持有者"职责，借助类加载机制保证线程安全。
- **客户端（Client）**：通过 `Singleton.getInstance()` 获取实例，而无需关心创建过程。

## 五、代码示例

本仓库在 `src/main/java/com/example/creational/singleton/` 下提供了三种实现以作对比：

- `Singleton.java`：饿汉式，类加载即创建实例。
- `LazySingleton.java`：懒汉式 + 双重检查锁（`volatile`），首次调用时创建实例。
- `StaticInnerClassSingleton.java`：静态内部类实现，懒加载且线程安全。
- `SingletonDemo.java`：演示入口，运行并对比三种实现的获取结果。

## 六、优缺点

**优点：**

- 保证全局唯一实例，避免不一致状态。
- 提供受控的全局访问点，比纯静态方法更灵活（可懒加载、可继承接口、可扩展）。
- 节省资源，对于重量级对象只创建一次。

**缺点：**

- 扩展困难：单例类不能被继承（构造私有），需通过实现接口来扩展。
- 隐藏依赖：调用方直接依赖单例静态方法，难以进行依赖注入与单元测试。
- 并发场景需小心实现，错误的懒加载可能产生多实例。
- 在分布式/多 ClassLoader 环境中"全局唯一"假设不成立。

## 七、应用实例

- **JDK**：`java.lang.Runtime#getRuntime()` 是典型的饿汉式单例；`System` 中通过内部 `System` 类暴露静态方法。
- **Spring**：默认情况下 Spring 容器中的 Bean 即为单例（容器级单例，由 `BeanFactory` 管理）。
- **Log4j / Logback**：`Logger` 工厂返回的 logger 通常按名称保持单例语义。
- **MyBatis**：`SqlSessionFactory` 在应用中通常作为单例使用。

## 八、与相关模式对比

| 模式 | 关键差异 |
|------|----------|
| 单例模式 | 关注"一个类只有一个实例"，并提供全局访问点。 |
| 静态工具类 | 不持有状态，所有方法为静态，无面向对象多态能力；单例可实现接口、支持懒加载、更易扩展。 |
| 多例模式（Multiton） | 单例的扩展，按 key 维护多个实例；单例可看作 key 固定的多例。 |
| 工厂方法 | 工厂方法关注"创建哪种对象"，单例关注"对象唯一性"；二者可结合：让工厂本身是单例。 |

## 九、运行示例

```bash
mvn -q exec:java -Dexec.mainClass="com.example.creational.singleton.SingletonDemo"
```
